# Imágenes del sitio

Usa esta carpeta para guardar imágenes optimizadas del sitio.

## Recomendaciones

- Formato recomendado: `.webp`, `.jpg` o `.png`.
- Tamaño hero recomendado: entre `1600px` y `2200px` de ancho.
- Tamaño galería recomendado: `900px` a `1400px` de ancho.
- Evita fotos borrosas, oscuras o tomadas con mucho desorden alrededor.
- Antes de subir a hosting, comprime las imágenes para mejorar la carga.

## Nombres sugeridos para proyectos reales

```text
proyecto-senaletica-seguridad-01.webp
proyecto-letrero-corporativo-01.webp
proyecto-vinilo-vidrio-01.webp
proyecto-identificacion-areas-01.webp
proyecto-grafica-vehicular-01.webp
```

Cuando tengas fotos reales, se pueden integrar a la galería reemplazando los placeholders actuales.
