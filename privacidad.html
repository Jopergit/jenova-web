Privacidad

Política de privacidad

Esta página explica cómo JENOVA Publicidad Gráfica utiliza los datos enviados en solicitudes de contacto y cotización.

Datos que se solicitan

El formulario puede solicitar nombre, empresa, teléfono, tipo de servicio, medidas aproximadas y mensaje del proyecto.

Uso de la información

Los datos se usan únicamente para responder solicitudes, preparar cotizaciones, coordinar trabajos y mantener comunicación comercial relacionada con el requerimiento.

Canales de contacto

La solicitud se prepara mediante correo electrónico. El teléfono publicado se utiliza para llamadas de contacto. Instagram está pendiente de activación. WhatsApp está disponible para solicitudes de cotización.

Conservación y eliminación

Los datos se conservan solo durante el tiempo necesario para atender la solicitud. Puedes pedir corrección o eliminación escribiendo a contacto.jenova@gmail.com.
